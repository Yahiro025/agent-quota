# React Bits components

These files are copied unchanged from the React Bits registry
(https://reactbits.dev, TS-CSS variants, fetched 2026-11-13):

- `Counter`: rolling digits for the quota display's headline percent.
- `SpotlightCard`: the pointer-following light on the quota display.
- `ShinyText`: the shimmer on "Checking…" while a refresh runs.

None of them needs a package beyond React. Fetch a newer version from the
registry instead of editing these files by hand.
