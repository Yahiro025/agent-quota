# One notch away

**90-second motion-graphics film for the complete Bloom + Agent Quota desktop companion.** This supersedes the archived quota-only draft. The user selected 90 seconds and requested much stronger motion graphics.

## Hook

**Your day. One notch away.**

Start so close to the notch that its rounded edge reads like a sculpted physical object. A crane move reveals its familiar shape. That one black surface opens into music, focus, files, controls, and agent quotas. The visual idea is many capabilities gathering into one coherent place.

End line: **Bloom. Room for your day.** Supporting identity: **With Agent Quota.**

## Production direction

- Whole non-dock companion: adaptive notch/live activities, music/visualizer, calendar/Pomodoro, shelf, command center, Wi-Fi/Bluetooth, weather/battery/hardware widgets, volume/brightness overlays and app mixer, Agent Quota, Overview, and personalization. Prior project direction preserves the user's existing dock.
- Actual project frontend screenshots and extracted elements; fictional media, file names, networks, devices and system readings. No live accounts, personal files or OS settings changes. Mock file paths are intercepted, not read from disk.
- Interactions in the film are authored demonstrations that sequence captured before/after states. They are not a live screen recording. Shelf masks match the measured native scroll viewport without claiming a filmed native scroll.
- Remotion 2.5D camera work, original vector stages and motion graphics, then FFmpeg mastering and QA. The Clawd prompt sets ambition and rigor; its mascot, plot, text ban and film-only pipeline do not apply.
- 1920×1080, 30fps, 2700 picture frames, 90 seconds, H.264/AAC stereo. Music + SFX and SFX-only editions use identical picture and cue timing.
- Real UI: matte black, Inter, authentic provider marks and quota usage colors. Warm white/graphite stages and original amber album artwork extend the palette. Preserve UI layout and status semantics.
- Bold choreography: macro-to-wide travel, soundtrack-driven visualizer, UI planes unfolding in perspective, shelf tiles flying into actual slots, directional camera handoffs, and a feature ensemble converging into one notch. Every move has a cause, a destination, and a settled reading moment. No random floating objects, logo spins, UI rain, repeated dissolves or beat-pumping the whole frame.
- Downloaded licensed music and foley only. No synthesized soundtrack. Provenance remains in credits.txt.

## Shotcraft mapping

`crane-rise-reveal`: focal point and zoom share one progress curve; ≥20-frame initial hold, 102-frame travel, ≥30-frame arrival hold. `spotlight-hero-card`: single media hero with side-lit lift/land, same perspective space, no repeated glints. `cursor-flyover`: cursor leads, camera follows, actual captured UI responds. `canvas-materialize-moves` / `panel-to-canvas`: reverse its curved migration into Shelf's measured slots; 6-frame stagger, geometry before dimensions; files are referenced, so do not falsely imply moving/deleting originals. `autolayout-gap-dial`: adapt single-parameter slider causality without adding design-tool handles. `mosaic-reframe`: x/y/w/h interpolate independently with 26–30-frame moves and a restrained stagger; editorial ensemble is not a claimed app layout feature.

Custom notch contour, visualizer stage, connection handoff, edge choreography and finale require direct frame/timing review. Do not claim exact Gallery reproduction. Font, palette, materials and data remain product-specific.

Visual study: https://www.apple.com/macbook-pro/ for hierarchy, material separation and scale; no Apple media or copy reused. Motion library: https://vincentwei1021.github.io/video-shotcraft/ .

## QA

Render and inspect a full low-resolution test, a frame every two seconds, transition frames and interaction responses. Reject clipped type, overlapping headlines, wrong UI state, inconsistent data, decorative noise and static-slide pacing. Then render HD and both audio editions. Verify codecs, dimensions, frame rate, 2700 video frames, duration, stereo, roughly −14 LUFS and true peak below −1 dBTP. Verify picture parity and retain capture/license records. Independent review must cover every feature family and the expanded motion brief before delivery.
